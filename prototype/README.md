# Pitch In prototype

Front-end-only demo of the Freedom Fest app for phone browsers. Plain HTML, CSS, and JS; no build step.

- Seeded demo data; the clock is frozen at Monday, Sept 7, 2026, 2:30 PM.
- Claims, stars, messages, crews joined, and shirt reservations are saved in the browser. Tap the clock pill for demo controls (view as Public / Helper / Team lead, Reset demo).
- Installable: Add to Home Screen opens it full-screen.
- Run locally: `python3 -m http.server` in this folder, then open http://localhost:8000.

Placeholders: fundraising numbers, T-shirt price, GoFundMe and Venmo links, chat names, and photo tiles.
